# Dados

Os 5 CSVs do dataset **RavenStack: Synthetic SaaS Dataset (Multi-Table)**, de River @ Rivalytics, publicado no Kaggle com licença MIT-like.
Os dados são totalmente sintéticos e não têm dados pessoais. A licença permite o uso em portfólio, desde que o autor seja creditado.

| Arquivo | Linhas | Chave |
|---|---|---|
| `ravenstack_accounts.csv` | 500 | `account_id` |
| `ravenstack_subscriptions.csv` | 5.000 | `subscription_id` → `account_id` |
| `ravenstack_feature_usage.csv` | 25.000 | `subscription_id` |
| `ravenstack_support_tickets.csv` | 2.000 | `account_id` |
| `ravenstack_churn_events.csv` | 600 | `account_id` |
