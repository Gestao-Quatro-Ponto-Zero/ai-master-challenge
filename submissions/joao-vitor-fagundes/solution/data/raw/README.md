# Raw data

Arquivos originais do dataset [CRM Sales Predictive Analytics](https://www.kaggle.com/datasets/agungpambudi/crm-sales-predictive-analytics), licença CC0, baixados em 28/08/2026.

O snapshot usado pela solução acompanha a submissão para permitir rebuild e testes sem depender do Kaggle. Para baixá-lo novamente e validar sua integridade:

```bash
python3 ../../scripts/download_data.py --output-dir .
```

O conteúdo original não deve ser alterado. Limpeza e normalização devem gerar arquivos separados.
