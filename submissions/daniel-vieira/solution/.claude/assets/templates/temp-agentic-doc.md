# Escopo

- Esta é uma referência recursiva (o próprio documento e sua formatação são a referência) para
  as regras de formatação da documentação de trabalho agêntico, especificamente os arquivos
  denominados 'CLAUDE.md', 'README.md' e 'SKILL.md', bem como os arquivos sob o diretório
  '.claude/rules/';
- Os arquivos 'CLAUDE.md' devem orientar como os agentes realizam o trabalho, incluindo como
  planejá-lo e controlá-lo; os arquivos 'README.md' devem descrever o escopo e os objetivos do
  projeto, bem como a maneira como ele é organizado.


# Este é um título de seção

## Este é um título de subseção

- Esta é uma diretiva de documentação. As diretivas podem ser uma definição ou afirmação
  (geralmente escritas na voz passiva), bem como uma regra ou comando direto (geralmente
  escritos no modo imperativo);
- Uma seção contém subseções ou diretivas, mas não ambas. Quando subseções são utilizadas, cada
  uma contém uma ou mais diretivas.

## Este é outro título de subseção

- Toda diretiva deve ser formatada como um item de lista (um marcador), em português formal, com
  as linhas quebradas em um máximo de 96 colunas e terminando com um ';' (ponto e vírgula).
  Apenas o último item de cada subseção deve terminar com um '.' (ponto);
- As subseções são separadas por uma linha em branco.


# Este é outro título de seção

## Este é outro título de subseção

- As seções são separadas por duas linhas em branco;
- Deixar uma única linha em branco ao final do documento.
