# Escopo deste índice

- Os registros de decisão do projeto são indexados neste documento, a fim de fornecer uma visão
  geral rápida das decisões e do seu estado atual;
- Para a fundamentação completa de uma decisão específica, um registro individual é mantido
  neste mesmo diretório, em um arquivo nomeado com o formato
  {adr-id}-{YYYY-MM-DD}-{slug-subject}.md.


# Como registrar ou atualizar uma entrada

- Registrar cada decisão como um item separado, um novo marcador, na seção "Decisões";
- Colocar a entrada mais recente no topo da lista;
- Utilizar o seguinte formato para cada entrada: '- {status} --- {adr-id} --- {YYYY-MM-DD} ---
  {assunto}';
- Atualizar o status de uma entrada sempre que o status da decisão mudar;
- Utilizar apenas caracteres imprimíveis, admitidos os caracteres acentuados do português;
- Quebrar as linhas em 96 colunas, e quando uma entrada exceder 96 colunas continuá-la na linha
  seguinte recuada com dois espaços, de modo que a continuação seja tratada como parte do mesmo
  marcador.
