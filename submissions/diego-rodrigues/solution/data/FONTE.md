# Procedência dos dados

- **Dataset:** CRM Sales Predictive Analytics, por agungpambudi
- **URL:** https://www.kaggle.com/datasets/agungpambudi/crm-sales-predictive-analytics
- **Licença:** CC0 (domínio público)
- **Data do download:** 11/11/2026

Os quatro CSVs nesta pasta (`accounts.csv`, `products.csv`, `sales_teams.csv`, `sales_pipeline.csv`) são cópia literal, byte a byte, dos arquivos do zip oficial. O `metadata.csv` do dataset não foi copiado. A integridade pode ser conferida com `shasum -a 256 -c SHA256SUMS` a partir desta pasta.
