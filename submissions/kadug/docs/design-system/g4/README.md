# G4 Design System Extraction

Artefatos para aplicar a identidade visual atual do G4 no front-end do desafio.

## Arquivos

- `design-system-audit.md`: auditoria e direcao visual.
- `tokens.json`: tokens normalizados para uso no dashboard.
- `page-map.json`: mapa das secoes observadas no site oficial.
- `reconstruction-spec.md`: orientacao de uso no Streamlit.
- `streamlit-theme.css`: CSS base opcional para injecao no app.
- `css-token-inventory.json`: inventario bruto gerado pela skill.
- `evidence/`: HTML, CSS e screenshots coletados do site oficial.

## Uso recomendado

Use `tokens.json` como fonte de verdade e `streamlit-theme.css` como ponto de partida. Nao copie logos, fotos, fontes ou assets proprietarios sem confirmar direitos de uso.
