# ✨ Dashboard Features & Capabilities

## 🎯 Core Scoring Engine

### Scoring Formula (0-100)
```
Total Score = Stage Score (0-25)
            + Account Score (0-20)
            + Seller Score (0-20)
            + Product Score (0-20)
            + Time Score (0-15)
```

### What You'll See:
- 🎨 Color-coded score badges (Green/Blue/Yellow/Red)
- 📊 Success probability percentage (0-100%)
- 🔍 Click to see detailed breakdown
- 📈 Trend over time

---

## 📋 Pipeline Tab Features

### Deal List Table
- ✅ All open opportunities ranked by score (highest first)
- ✅ Sortable columns: Agent, Account, Product, Stage, Days, Score, Success %
- ✅ 5 color-coded deal stages
- ✅ Search and filter in real-time
- ✅ View individual deal details

### Column Information:
| Column | What It Shows |
|--------|--------------|
| **Sales Agent** | Who owns the deal |
| **Account** | Company name & sector |
| **Product** | Product being sold |
| **Stage** | Pipeline status (Prospecting/Engaging) |
| **Days** | Days on pipeline (0-365) |
| **Score** | Success probability (0-100) |
| **Success** | Win likelihood (0-100%) |
| **Action** | View details button |

### Sorting Capability
- Click any column header to sort ascending/descending
- Default: Highest scores first
- Works with all columns

## 🎯 Use Cases & Examples

### Use Case 1: "Find My Best Opportunities"
1. Go to Pipeline tab
2. All deals sorted by score (highest first)
3. Top 10 deals are your priority
4. Spend time on 75-100 scored deals first

### Use Case 2: "Understand Why a Deal Scores Low"
1. Click on the score badge
2. See score breakdown
3. Identify weak factors (account size, seller experience, time)
4. Decide if deal needs intervention or focus

### Use Case 3: "Focus on Specific Product"
1. Use Product filter
2. See all deals for that product
3. Compare with analytics
4. Learn which products sell best

### Use Case 4: "Analyze My Performance"
1. Use Sales Agent filter (select yourself)
2. See all your open deals
3. Sort by score
4. Go to Analytics tab
5. Compare with top performers

### Use Case 5: "Find Quick Wins"
1. Filter by Deal Stage = "Engaging"
2. Sort by Score = Descending
3. Minimum Score = 70
4. These should close soon!

### Use Case 6: "Identify Problem Deals"
1. Find deals with low scores (< 45)
2. Check Time on Pipeline (> 120 days)
3. Consider if worth pursuing
4. Or focus on high-probability deals instead
