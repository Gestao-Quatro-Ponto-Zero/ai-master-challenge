# A planilha, exportada

A planilha `sales_pipeline` é o motor do Lead Scorer. Esta pasta é a cópia reproduzível dela, pra quem não tiver acesso ao Google Sheets:

- `formulas.md`: toda fórmula, aba por aba, célula a célula (fórmulas preenchidas pra baixo aparecem uma vez, com o intervalo).
- `config.md`: as entradas e os valores da aba `Hoje` (relógio, modo de dono, cortes, ordem dentro do passo).
- Os dados de entrada são os CSVs em `../data`.

Link de leitura da planilha original: https://docs.google.com/spreadsheets/d/1IjZSZTpzergXYVKPxf-IUJwsss5xD9P_Nch5KX3IMDc/edit
