# Dados brutos

Este diretório receberá, sem versionamento, os cinco arquivos oficiais:

- `ravenstack_accounts.csv`;
- `ravenstack_subscriptions.csv`;
- `ravenstack_feature_usage.csv`;
- `ravenstack_support_tickets.csv`;
- `ravenstack_churn_events.csv`.

## Política

- os arquivos devem ser obtidos da fonte oficial indicada no Challenge 001: o dataset **SaaS Subscription & Churn Analytics** no Kaggle, publicado sob licença MIT;
- os CSVs não devem ser versionados;
- nenhuma análise será iniciada sem os cinco arquivos;
- nomes reais, schemas, chaves, tipos e granularidades serão verificados na Fase 1;
- nenhum schema presumido será tratado como definitivo;
- dados sintéticos não serão utilizados como substitutos silenciosos;
- dados brutos são imutáveis e nunca serão sobrescritos por transformações.

Nenhum CSV ou dado de exemplo foi criado na Fase 0.
