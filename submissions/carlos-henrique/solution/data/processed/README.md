# Dados processados

Este diretório poderá conter somente resultados derivados e reproduzíveis, como:

- event log validado;
- tabelas consolidadas;
- datasets analíticos;
- agregações temporais.

## Política

- arquivos grandes não serão versionados sem necessidade justificada;
- todo artefato deverá possuir script de geração e linhagem documentada;
- contagens e chaves deverão reconciliar com as fontes;
- nenhuma transformação poderá sobrescrever dados brutos;
- saídas deverão ser recriáveis a partir das fontes oficiais e dos parâmetros registrados.
