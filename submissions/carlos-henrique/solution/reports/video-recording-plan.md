# JourneyGraph Video Recording Plan

## Before Recording

- [ ] Confirm the final approved commit and clean working tree.
- [ ] Run the local validation commands from the reviewer guide.
- [ ] Start the application in production mode and open all seven routes.
- [ ] Use a clean browser profile with no personal tabs, extensions, bookmarks bar, or autofill prompts visible.
- [ ] Set the capture viewport to 1920×1080 and browser zoom to 100%.
- [ ] Disable notifications, messaging pop-ups, calendar alerts, and operating-system banners.
- [ ] Keep the cursor visible and use the default pointer size.
- [ ] Confirm no terminal, private path, account identifier, PII, credential, or external service is visible.
- [ ] Test the microphone for clarity, input level, room noise, and clipping.
- [ ] Keep the teleprompter/script on a separate non-captured display or printed page.
- [ ] Rehearse once with a timer; accepted duration is 2:45–3:15.

## Recording Settings

| Setting | Recommendation |
|---|---|
| Resolution | 1920×1080 |
| Frame rate | 30 fps |
| Orientation | Landscape |
| Capture area | Browser only |
| Microphone | Clear voice input, tested before recording |
| System audio | Disabled unless a verified product sound is intentionally required |
| Webcam | Not required |
| Background music | Not required |
| Cursor | Visible, deliberate movement |
| Browser zoom | 100% |

## Recording Sequence

1. Start the production application before capture.
2. Verify `/`, `/quality`, `/journeys`, `/graph`, `/watchlist`, `/experiments`, and `/governance` in prepared tabs.
3. Start recording on the title card or the fully loaded Executive Overview.
4. Follow the timestamps and route order in [video-storyboard.md](video-storyboard.md).
5. Use only the planned journey, graph node, watchlist item, and experiment interaction.
6. Park the cursor before delivering each decision or limitation.
7. End on Governance, complete the closing sentence, hold for two seconds, then stop.
8. Save the local master using `journeygraph-demo-en-1080p-v1.mp4`.
9. Review the entire file before editing or upload.

## Retake Criteria

Record a new take if any of the following occurs:

- navigation error or unintended tab exposure;
- clipped text, horizontal overflow, or incorrect zoom;
- internal ID, PII, credential, notification, or private local path appears;
- pause longer than five seconds or narration loses the approved sequence;
- metric, cutoff, experiment status, or governance claim is stated incorrectly;
- total duration is outside 2:45–3:15;
- browser console or broken application state becomes visible;
- cursor movement is erratic or obscures key text;
- audio clips, drops, or becomes difficult to understand.

## Post-production

1. Trim only dead time at the beginning and end.
2. Normalize voice audio; do not add unnecessary system audio.
3. Add the approved English subtitles and synchronize every cue to the final cut.
4. Add a short intro title and final title using the thumbnail wording.
5. Use direct cuts or a restrained crossfade; avoid excessive transitions.
6. Export at 1920×1080, 30 fps, then watch the exported file from start to finish.
7. Verify subtitle readability, route order, metrics, privacy, duration, and final frame.

## Publication Boundary

Recording, editing, upload, visibility selection, and link verification are `PENDING_USER_ACTION`. This document prepares those steps but does not authorize or perform them.
