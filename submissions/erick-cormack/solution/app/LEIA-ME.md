# Código do app (Lovable)

O código do front-end fica no projeto do Lovable. Para trazê-lo para cá:

1. No editor do Lovable, conecte o projeto ao GitHub (opção GitHub no editor). Ele cria um repositório com todo o código.
2. Copie o conteúdo desse repositório para esta pasta `app/`, ou substitua este arquivo por um link para o repositório.

Configuração para rodar localmente: `VITE_SUPABASE_URL` e `VITE_SUPABASE_PUBLISHABLE_KEY`, depois `npm install && npm run dev`.
